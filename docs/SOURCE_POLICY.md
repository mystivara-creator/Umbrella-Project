# Source policy and licenses

Umbrella Project is **independent in governance and engineering**, not a claim that Linux/Android code was written from scratch.

- Select an upstream Android/Linux kernel and device/vendor sources matching the actual phone and firmware.
- Record upstream repository URLs, revision SHAs, toolchain provenance, and all patch origins.
- Preserve existing copyright notices, attribution, and applicable GNU GPL and other license obligations.
- Any source redistribution must meet corresponding source and license requirements. Avoid copying third-party branding or presenting inherited code as original work.
- Do not assign a blanket new license to upstream code. Establish a license for original repository materials and patches separately with due diligence.
- Do not publish proprietary vendor binaries without redistribution rights.

Before importing a kernel baseline, add `docs/UPSTREAM.md` with exact source URLs, revisions, license notes, and deviations.
